# 紫鸾·万翎 (Ziluan Wanying) v1.0

基于**晶脉哲学 (Jingmai Philosophy)** 四重公理构建的大规模AI物理集群智能体系统。支持10000个模块化机器人通过“触”与“缠”的关系网络自组织协作，并内嵌**晶脉·天枢 (CPRC)** 场域健康引擎与**仿生记忆皮层**，实现自我感知、矛盾调谐与跨世代经验传承。

## 🚀 核心特性

*   **万翎集群 (Wanying Swarm)**：支持1000+智能体节点并行运行，通过消息总线形成**触**(有向通信)和**缠**(共存关系)网络。无中央调度器，集群行为完全自组织涌现。
*   **物理模块化形态**：每个模块为边长30cm的立方体，内置推进器、传感器和机械臂，可动态锁接为任意形态。形态不是被设计的，而是从局部规则中涌现的。
*   **仿生记忆皮层**：基于场域驱动的连续记忆唤醒机制。当系统检测到矛盾张力(A值)升高时，自动唤醒相关历史经验，帮助系统回归谐振态。
*   **CPRC自调谐引擎**：内嵌`晶脉·天枢`感知器，通过温度动力学方程 `dτ/dt = -α·(dH/dt)/τ + β·(d²H/dt²) - γ·τ` 连续调节探索-利用平衡。
*   **场域感知增强**：新增U值峰值反转、A值活性丧失、σD趋势收敛等检测能力，比经典预警路径更早感知场域相变前兆。
*   **全链路审计**：所有记忆操作、形态变化、调谐决策均附带完整审计日志，可追溯、可复盘。

## 🧠 理论根基：晶脉哲学四重公理

本项目是晶脉哲学在工程层面的完整显形，所有代码均严格遵循以下公理：

| 公理 | 核心命题 | 工程实现 |
| :--- | :--- | :--- |
| **关系本体论** | 存在即被关系网络定位 | 模块同一性由关系场域位置界定，触和缠是存在的基本方式 |
| **矛盾动力论** | 矛盾是系统演化的能量源 | A值度量矛盾张力，张力驱动形态重组、记忆唤醒和温度调谐 |
| **实践介入论** | 认识即介入，介入痕迹必须可审计 | 所有决策链路附带审计记录，完整因果链可追溯 |
| **谐振调谐论** | 系统朝向更高和谐度自组织 | 集群通过H值自组织趋近动态平衡，无外部预设优化目标 |

## 🛡️ 严防工具理性悖论

所有调节动作均在场域内部完成，**不引入任何外部规则层**。降温是调整模块自身参数而非外部强制截断，形态重组是模块基于局部信息自主涌现，记忆唤醒被A值驱动而非定时调用。

## 📦 项目结构

```
ziluan_wanying/
├── core/                  # 核心数据结构 (场快照, 矛盾边, 镇定动作)
├── network/               # 通信总线与关系图 (触和缠的物理实现)
├── agents/                # 智能体节点 (紫鸾实例)
├── physical/              # 物理模块层 (连接器, 形态图, 物理模块)
├── emergence/             # 涌现引擎 (形态自组织驱动核心)
├── memory/                # 仿生记忆皮层 (记忆存储, 唤醒, 演化)
├── enhanced_sensors.py    # 场域感知增强模块
├── physical_cluster.py    # 物理集群管理器
├── orchestrator.py        # 集群编排器
└── examples/              # 演示脚本
```

## ⚡️ 快速开始

**1. 安装依赖**
```bash
pip install numpy networkx

**2. 运行演示**
```bash

# 运行物理形态演化演示 (模块化机器人自组装)

python enhanced_sensors.py
```
